Apple Health → FORM

Use an iPhone Shortcut to export daily summaries to Files. Import that file into FORM. This requires your Health read permission on the iPhone. FORM itself has no direct HealthKit permission and no continuous background sync.

Start with one day of steps

  1. In Shortcuts, create Export to FORM.
  2. Add Find Health Samples. Select Steps. Restrict the Start Date to one calendar day using its start and end boundaries. Select one Source, such as your Apple Watch. Grant Health read access when prompted. Start with yesterday so the day is complete.
  3. Add Count for the results. If the count is zero, stop the shortcut. No returned samples can mean no data or no permission; never turn that into a zero reading.
  4. Add Calculate Statistics, choose Sum, and explicitly select the Health Samples as input (not the Count).
  5. Use Format Date with Custom format yyyy-MM-dd for the selected calendar day. Use lowercase yyyy; the date must match your query window. Use that day, not the current date for a historical query.
  6. Add a Dictionary. Add Text date = Formatted Date, Text source = the selected source name, and Number steps = the Statistics result. Choose the result as a variable, not literal text.
  7. Add a List containing that Dictionary. Add a second Dictionary with Number version = 1 and Array days = the List.
  8. Add Get Text from Input with the second Dictionary as input, Set Name to form-health.json, then Save File. Choose a location in Files.
  9. Run the shortcut, then open FORM → Health. Unlock or create your vault, choose form-health.json, review the readings and source, then save. Back up your encrypted vault in Settings.

Action wording can vary with iOS. The Shortcut is created on your iPhone; this guide does not install or authorize it. Test the first output and compare with that source’s samples before using it regularly. Phone and Watch samples can overlap; summing all sources can overcount. A single-source import is not guaranteed to match Health’s combined daily total.

Expected file shape

This describes the structure. Replace the placeholders with the Shortcut’s date, selected source, and numeric Sum; do not import this illustration as data. 

{
  "version": 1,
  "days": [
    {
      "date": "YYYY-MM-DD",
      "source": "YOUR SELECTED SOURCE",
      "steps": STEPS_SUM
    }
  ]
}

Optional daily fields

The first Shortcut only exports steps. Other fields are accepted when explicitly supplied in the units below. Omit absent or permission-denied readings. Do not use zero as a substitute. Keep one summary per date. If different fields use different sources, include that mapping in the source label.

Field Unit / meaning
steps Integer count for the queried day and selected source
activeEnergyKcal Active energy, kcal; not basal energy or food intake
restingHeartRateBpm Resting heart rate, beats/minute; not general heart rate
sleepHours Hours asleep; exclude awake/in-bed time and overlapping stages
dietaryEnergyKcal Food energy logged, kcal; not calories burned
weightKg Latest weight for that date, kilograms; not a sum

FORM accepts up to 366 dates per import and files smaller than 1 MB. Importing a date again replaces its entire previous summary rather than adding totals. Include all fields you want to retain for that date. The dashboard shows today's imported readings only; older days stay in Health history with their source and import timestamp. Import timestamps indicate when FORM saved the file, not when the Health readings were collected.

Chat stays in your project

FORM's Chat tab opens your existing Health & Fitness project in ChatGPT. Unlock the vault to review and copy a summary first. Pasting into ChatGPT is your choice; FORM does not send readings or synchronize project chats.

Privacy

The export file is plaintext Health data in Files. Store it privately. FORM encrypts its saved copy in your local vault. No raw exports are uploaded to GitHub, and no API key is needed. Use encrypted backups because clearing website data can erase the vault.
